## Structure

Each topic is self-contained under `topics/<topic>/` and may define its own foundations, deep dives, research notes, roadmap, and learning path. Cross-topic implementation work stays in [[projects/README|Projects]].

Add a topic only when its first real note is ready. DevOps and econometrics, for example, should eventually become `topics/devops/` and `topics/econometrics/` rather than new top-level numbering schemes.
